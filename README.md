# Punktestand

Eine mobile Punkte-App für mehrere Spieler – ohne Frameworks und ohne externe Abhängigkeiten.

**Live-App:** <https://jejepage.github.io/single-file-score-app/>

## Funktionen

- frei wählbare Spieler und Zielmarke
- positive und negative Punkte
- ein Rückgängig-Schritt
- neue Runden mit denselben Spielern
- manuelles Spielende mit Rangliste
- lokale Speicherung im Browser
- iPhone-optimierter Hell- und Dunkelmodus
- eigenes App-Icon für den iPhone-Home-Bildschirm

## Verwendung

`index.html` direkt im Browser öffnen oder die Live-App verwenden. Auf dem iPhone kann sie in Safari über **Teilen → Zum Home-Bildschirm** installiert werden.

Die vollständigen Anforderungen stehen in [SPEZIFIKATION.md](SPEZIFIKATION.md).
